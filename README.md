An original offline browser game about positioning a frigate to fire broadside cannons. Break a four-encounter blockade, collect wreck salvage, choose upgrades, and defeat the command dreadnought.

## Play

Open `game/index.html` in a desktop browser. No install, server, network request, or account required.

- W / S: throttle and reverse
- A / D: steer
- Space: fire port and starboard broadsides
- Shift: surge and briefly evade incoming shots
- P / Escape: pause
- M: toggle procedural audio
- Q: switch round shot / chain shot (slows enemy rigging)
- E: deploy smoke screen (10-second cooldown)
- 1 / 2 / 3: choose a drydock refit between sectors

Cannons fire sideways. Align enemies beside the hull, fire, and maneuver during reload. Collect wreck salvage to repair 18 hull. Clear the harbor, escort a merchant through the reef, capture a caldera signal, then destroy the fortress dreadnought. Campaign unlocks and medals persist locally. Retry any unlocked sector from the campaign chart.

## Build the bounty output

Requires Node.js 22.18 or newer.

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies the static game and real browser screenshots, then uses the unchanged kit library to write `out/dossier.json`.

All visual assets and audio are generated by the game's own code. The game uses native Canvas 2D, CSS, and JavaScript with no third-party runtime dependencies. `vendor/makefun-game.ts` is the competition's unchanged dossier builder.

## Validation

The campaign simulation was exercised in real Brave Chromium through ordinary helm/fire input state: harbor, escort, signal capture, refit transitions, and final dreadnought victory without altering health or force-clearing enemies. Keyboard smoke, weapon switching and pause/resume were also tested with zero JavaScript errors. Screenshots are captured from the actual running game's code.

## Source layout

- `state.js`: shared state, objective/sector definitions
- `storage.js`: local campaign saves and medals
- `combat.js`: ship motion, weapons, enemy roles, hits and salvage
- `campaign.js`: mission objectives and progression
- `effects.js`: procedural audio and particle lifetimes
- `ui.js`: campaign chart, refits, debriefs and HUD
- `render.js`: sea, islands, ships, hazards and tactical overlays
- `boot.js`: frame loop, keyboard and read-only diagnostics
